01

ANTES DE EMPEZAR

Prepara tu equipo

Unos minutos de preparación pueden ahorrarte horas de problemas.

!
Haz una copia de seguridad primero

Instalar un sistema operativo puede borrar datos. Guarda tus archivos importantes y confirma qué disco y particiones vas a utilizar antes de continuar.

⌁ MEMORIA 8 GB recomendados

4 GB mínimo; más memoria mejora Quickshell y la multitarea.

▤ ALMACENAMIENTO 100 GB disponibles

SSD recomendado. Reserva espacio adicional para tus aplicaciones y archivos.

⌘ MEDIO DE INSTALACIÓN USB de 8 GB o más

Necesitarás otra computadora para preparar la memoria USB.

Arranca desde la USB e instala

03

HYPRLAND + QUICKSHELL

Instala el escritorio

II-P3DROVFX está construido sobre illogical-impulse, los dotfiles de Hyprland de end4.

CachyOS→ Hyprland→ end4 / illogical-impulse→ II-P3DROVFX
!
No instales las dos configuraciones una encima de la otra

Para un sistema limpio, el instalador predeterminado de II-P3DROVFX prepara la base y aplica su configuración. No hace falta ejecutar por separado el instalador de end4.

◈
Requisitos de II-P3DROVFXConfirma compatibilidad en el repositorio antes de instalar.
Hyprland 0.56.1+ Matugen 4.1.0+ Quickshell 0.3.0+

RECOMENDADA · SISTEMA LIMPIO

Instalación completa

Prepara la base de illogical-impulse y después instala II-P3DROVFX. Úsala si acabas de instalar CachyOS.

TERMINAL
git clone --recurse-submodules https://github.com/P3DROVFX/ii-p3drovfx.git
cd ii-p3drovfx
./setup-ii-p3drovfx.sh install
Guía oficial de instalación ↗
BASE end4 YA FUNCIONANDO

Solo configuración

Usa este modo si illogical-impulse ya funciona en tu sesión. Instala la configuración de Quickshell de II-P3DROVFX.

TERMINAL
git clone --recurse-submodules https://github.com/P3DROVFX/ii-p3drovfx.git
cd ii-p3drovfx
./setup-ii-p3drovfx.sh
Ver los dotfiles de end4 ↗

Estos comandos corresponden a los modos publicados por II-P3DROVFX. El instalador muestra las acciones antes de ejecutarlas; revisa cada cambio y consulta su wiki si necesitas detalles.
